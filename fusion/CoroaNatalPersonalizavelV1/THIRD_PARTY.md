# Fontes e bibliotecas incluídas

As bibliotecas são distribuídas localmente para o formulário funcionar sem rede. Os cabeçalhos originais e as licenças estão preservados em `vendor/` e `fonts/`.

| Recurso | Versão / origem | Licença |
| --- | --- | --- |
| Clipper JavaScript | clipper-lib 6.4.2, npm | Boost Software License 1.0; ver cabeçalhos com as atribuições a Angus Johnson e Timo |
| Earcut | earcut 2.2.4, npm | ISC |
| OpenType.js | opentype.js 1.3.4, npm | MIT |
| fflate | fflate 0.8.2, npm | MIT |
| Pacifico | Google Fonts, `ofl/pacifico/Pacifico-Regular.ttf` | SIL Open Font License 1.1 |
| Leckerli One | Google Fonts, `ofl/leckerlione/LeckerliOne-Regular.ttf` | SIL Open Font License 1.1 |

Fontes obtidas em 12/11/2026 de [google/fonts](https://github.com/google/fonts). Os ficheiros originais das fontes não foram modificados. O pequeno engrossamento aplicado aos contornos no modelo não altera os ficheiros das fontes.

As versões exatas das bibliotecas estão guardadas em `vendor/`; não são descarregadas quando o utilizador abre o formulário. O perfil de impressão completo é derivado do projeto indicado em `profile-source.json`.
