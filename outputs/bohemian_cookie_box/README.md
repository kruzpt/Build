# Caixa Maria — Bohemian Rhapsody

Versão atual: [V2](v2/README.md), com silhueta frontal redesenhada. [V1](v1/README.md) preservada para comparação. Projeto paramétrico provisório para seis bolachas Maria, Bambu A1, bico 0,4 mm e PEI liso.

O projeto referido como existente noutra sessão não estava disponível neste ambiente. A V1 foi reconstruída a partir do pedido fornecido; a V2 mantém as dimensões e substitui a silhueta. Não é uma recuperação do OpenSCAD anterior.
