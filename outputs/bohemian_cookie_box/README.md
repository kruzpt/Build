# Caixa Maria — Bohemian Rhapsody

Versão atual: [V1](v1/README.md). Projeto paramétrico provisório para seis bolachas Maria, Bambu A1, bico 0,4 mm e PEI liso.

O projeto referido como existente noutra sessão não estava disponível neste ambiente. Esta V1 foi reconstruída a partir do pedido fornecido, mantendo dimensões ajustáveis. Não é uma recuperação do OpenSCAD anterior.
